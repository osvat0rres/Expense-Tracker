# Expense Tracker
This application is still in progress.
# Basic Features
1. User registration/Login
   - create account
   - Login/logout
   - Password Authentication
2. Add an expense
3. view Expenses
4. edit expensive
5. Delete expenses
6. expense categories
   - food
   - entertainment
   - Bills
   - shopping
   - education
   - other
7. monthly dashboard
- will tell you how much you spend in a month or week
8. Search and Filter
9. Monthly/weekly repost
10. Budget system
11. Recurring expenses

 pip install djangorestframework-simplejwt

npx create-react app frontend
